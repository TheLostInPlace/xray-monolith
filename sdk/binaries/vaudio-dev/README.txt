Vercidium Audio 1.10.1 dev build, for debugging the raytraced sound.

To use it, copy vaudionative.dll and glfw3.dll from this folder into bin, over the production vaudionative.dll there.
Start vaudio-debug-window.exe from this folder to watch the rays while the game runs.
Copy the production vaudionative.dll back for normal play, since the dev build is slower.
